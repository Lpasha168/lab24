Калькулятор с тремя режимами работы:

###  Стандартный режим
- Базовые арифметические операции (+, -, *, /)
- Квадратный корень (√)
- Возведение в степень (x^y)
- Проценты (%)
- Смена знака (+/-)
- Десятичная точка
- Кнопки CE (очистка ввода) и C (полная очистка)

###  Научный режим
- Тригонометрические функции (sin, cos, tan)
- Десятичный логарифм (log)
- Поддержка углов в градусах

###  Режим программиста
- Перевод в двоичную систему (Bin)
- Перевод в шестнадцатеричную систему (Hex)
- Работа только с целыми числами

###  История операций
- Сохранение всех выполненных операций
- Возможность использовать результат из истории (двойной клик)
- Очистка истории
- Сохранение истории в файл
- Загрузка истории из файла

## Инструкции по сборке и запуску

### Требования
- Qt 6.0 или выше
- CMake 3.16 или выше
- Компилятор с поддержкой C++17 (MSVC, GCC, MinGW)

### Сборка через Qt Creator 
1. Откройте Qt Creator
2. Выберите File → Open File or Project
3. Найдите и выберите CMakeLists.txt в корне проекта
4. Настройте комплект сборки (Kit)

5. Нажмите Build → Build All (или Ctrl+B)
